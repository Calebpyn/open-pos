🧩 Plugins

Programas que se instalan sobre Open POS (por ejemplo, un inventario). Cada uno corre aparte: si uno falla, la venta sigue funcionando. Solo instala plugins de alguien de confianza: un plugin tiene acceso a esta computadora.

Para instalar uno, copia su carpeta a plugins/ junto a la base de datos y reinicia Open POS.
